# BEFORE → AFTER — the backbone of the talk

> **Thesis.** The traditional environmetrics workflow is a *person* driving *specialist tools* over *days to weeks*: pull the data by hand, write bespoke model code, tune it, validate it, plot it, and write it up — one task, one expert, serially. The **AFTER** workflow keeps the same scientist in charge of every scientific judgment, but hands the mechanical labor to **Claude Code (an agentic coder)** wired to **AI-for-science models** (climate/weather foundation models, time-series foundation models, structured-extraction LLMs, vision models). The agent fetches the data, writes and runs the Python, fits the model — often a pretrained SOTA model used *zero-shot* — validates against the rigor checklist, and drafts the report, in **minutes of wall-time**. The claim is **science ≈ 100× faster**, and the honest unit of that claim is *person-time → wall-time*, not "AI is 100× smarter."

This document is the master comparison that the slides are built on. Every row is a task *class* in environmental statistics; every row points at a repo experiment (`ExpNN`) whose `results/` folder will hold the *real, committed* numbers. **Numbers below are deliberately ranges or `(measured in ExpNN)` placeholders** — the experiments fill in the truth; the slides never show invented figures.

---

## How to read the table

- **BEFORE** = the method an environmetrician uses today: the tool, who runs it, the rough *person-time*, and the artifacts produced.
- **AFTER** = Claude Code orchestrating a named AI-for-science model: the *wall-time* (mostly agent + compute, minimal human attention), and the artifacts.
- **Speedup** = `BEFORE person-time ÷ AFTER wall-time`. Reported as an order-of-magnitude band until `ExpNN` measures it. **This is a labor/latency ratio, not an accuracy claim.**
- **Rigor safeguard kept** = the statistical-validity check that the human still owns (encoded in the `env-stats-validate` skill). The acceleration does **not** remove it.

## What "AFTER" does **NOT** change

The acceleration is in *labor and latency*, not in *scientific responsibility*. The human scientist still owns — and the `env-stats-validate` skill enforces — all of the following:

1. **Assumptions.** Stationarity, distributional choices (GEV vs GPD), independence, error structure — chosen and justified by the human, not by the agent's default.
2. **Model choice & framing.** Picking the right model class and the right *baseline* to beat is a scientific decision. The agent proposes; the scientist disposes.
3. **Multiple-testing & selection effects.** Testing many sites/seasons/species inflates false positives. Corrections (FDR/Bonferroni) and pre-registration of the question remain mandatory — the agent does not get to "find significance."
4. **Uncertainty.** Point estimates without intervals are not results. Confidence/credible intervals, prediction variance, and conformal coverage stay in every deliverable.
5. **Leakage & validation design.** Spatial blocking, temporal walk-forward, basin/station grouping — the *split* is a scientific choice the human signs off, because the agent will happily report an over-optimistic leaked score.
6. **Peer review & accountability.** A faster draft is still a draft. Reproducibility (committed code + seeds + data provenance), honest reporting of negative results, and human-authored final claims are non-negotiable. Speed never substitutes for review.

**One-line summary for the slide:** *AFTER changes who does the typing, not who is responsible for the science.*
